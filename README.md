# AI-Based Network Intrusion Detection System

This project implements an AI-powered Network Intrusion Detection System using
Machine Learning (Random Forest).

## Features
- Trained on CIC-IDS-2017 (Friday DDoS dataset)
- Detects malicious and benign traffic
- Streamlit-based interactive dashboard

## Tech Stack
- Python
- Streamlit
- Scikit-learn
- Pandas
